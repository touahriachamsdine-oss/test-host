# Global Deep-Tech Observatory — Scale to 4,500 Real Companies

Status: approved 2026-09-22 (amendments: grow total to ~4,500, exclude all Israel entries everywhere, push to git when done)

## Objective
Grow the startup inventory from ~969 to ~4,500 unique entries, all of them real companies sourced from public corpora, enriched per-company with generated analysis across en/ar/fr, and extend the detail page with insight sections. Remove every entry whose country is Israel from all datasets and from the database.

## Content integrity rule
- Identity facts (name, country, industry, valuation, founders, founding year) are real, sourced from public corpora:
  - Wikipedia unicorn list (~1,300 companies)
  - Second corpus (Y Combinator directory or fallback Wikipedia industry lists) for the remainder
- Analysis fields (concept, main sellers, team recommendation, build approach, product issues, Algeria value, difficulty metric) are platform-generated from real facts. The UI carries a small "generated analysis" note so they are never presented as the company's own claims.

## Data sources (allowed)
1. `https://en.wikipedia.org/wiki/List_of_unicorn_startup_companies` (confirmed fetchable)
2. `https://en.wikipedia.org/wiki/List_of_Y_Combinator_companies` (or Wikipedia industry lists as fallback)

## Schema additions
- `startups`: concept (text), main_sellers (jsonb), build_approach (text), product_issues (jsonb), algeria_value (text), team_rec (jsonb, roles totaling max 6), difficulty_score (smallint 0-100), difficulty_breakdown (jsonb), source_tier (text), source_note (text)
- `startup_translations`: concept, main_sellers (jsonb), build_approach, product_issues (jsonb), algeria_value, team_rec (jsonb) — ar/fr locales

## Israel exclusion rule
Remove any startup whose country field contains "Israel" (case-insensitive), incl. multi-country entries (e.g. "United States and Israel"). Applied in generator, all source files, and a DB cleanup.

## Difficulty metric
0-100 composite from transparent formula: technical complexity, capital intensity (valuation/sector), regulatory and market friction, talent availability, time-to-MVP, Algeria replication factor. Stored with per-factor breakdown.

## Team recommendation
2-6 specialty roles per company with counts, total hard-capped at 6.

## UI (startup detail page only)
New sections: Concept, Market landscape / main sellers, Team recommendation (6-cap), Build approach, "Fix these to make it 1,000x better", "Why it matters for Algeria", Difficulty meter with breakdown, source + generated-analysis note. Section labels added to en/ar/fr catalogs.

## Seeding & testing
- New builder script generates data/global v2 entries + translations (deterministic, seeded RNG, no repeats)
- Extended seed scripts insert new columns; DB cleanup removes Israel rows
- Generator unit tests: zero name repeats, team <=6, score in 0-100, all locales present, no Israel entries, valid JSON
- Gates: vitest, tsc --noEmit, eslint, next build

## Delivery
Pipeline built and run in batches up to ~4,500; single git commit + push on completion.
